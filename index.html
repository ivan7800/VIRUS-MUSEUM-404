      04 / PROYECTO
      Memoria del malware.
      Un espacio para comprender la historia de la seguridad informática desde la curiosidad, no desde el riesgo.
      ¿Qué es VIRUS MUSEUM 404?
      Una aplicación web estática, local y educativa. Las recreaciones futuras se implementarán con HTML, CSS y JavaScript en escenarios ficticios, nunca ejecutando código de amenazas reales.
      Principios
      • Sin muestras reales de malware, exploits ni propagación efectiva.
      • Sin descargas externas, servidores, cuentas o telemetría.
      • Fichas separadas de la lógica visual de simulación.
      • Accesibilidad, rendimiento y compatibilidad con GitHub Pages.
      • Fases verificables: las funciones pendientes estarán identificadas como tales.
